# LinkedIn post — draft 8 (Rasa, voice, easy to build)

Voice AI is hard, but with Rasa it's way simpler.

A voice agent needs speech recognition, speech synthesis, and turn-taking. It also needs low latency, tool calling, and an interface to test it. Rasa packages all that so we can start with solving the real business problem instead of figuring out the plumbing.

I built a simple voice agent that can help me navigate the AI Engineering job market. I asked Grok to use the latest version of Rasa, gave it the dataset and a DeepGram key. And that was it. You can see the result in the demo.

It can be further improved, but it gives me a great starting point.

Give your coding agent a real business problem, point it at your data, and let it build the first version with Rasa.
